# 局部编辑边界与验收

用于局部修改、连续改图和“其他不变”的任务。不要把这个流程强加给从零创作或用户已明确授权的整体重绘。

## 先固定修改范围

内部记录四件事，无需让用户填写表格：

- **基准图**：用户当前指定的图，或最近明确认可的版本。失败结果不能自动升级为基准。
- **可改内容**：对象、属性和所在区域。例如换船型可改船体轮廓，但不等于可改地面。
- **保护内容**：具体位置、结构、纹理、人物及已确认成果。“保留沙漠氛围”不能代替“保留原沙脊、沙纹和人物位置”。
- **接合范围**：轮廓变化、遮挡恢复或融合所需的最小区域。新增阴影和反射可能触及保护内容，不能默认允许。

新要求与已有保留约束并存时，先选择不破坏保护区的实现。例如用对象自身的透视、方向、体量或局部裁切增加压迫感，保留整张图的摄影机与背景。如果要求确实必须移动摄影机、改变地面投影等，明确冲突，只询问必要取舍；不能自行加一句“允许重构背景”。用户明确选择整体改图时再扩大范围，不继续沿用已被用户撤销的旧限制。

## 区分三种执行能力

1. **仅写提示词**：交付可改项和具体保护项；不声称已完成区域锁定。
2. **生成工具编辑**：自然语言和某些蒙版可能只是引导，先核对实际工具的边界能力。没有依据不得把提示词中的区域要求说成工具已设置的硬约束。
3. **严格保护**：宿主已有授权且支持确定性合成时，可保留原图的保护区域，只引入编辑区域，并在保护区域之外进行过渡。否则说明当前只能给待验收候选，不能承诺像素不变；继续可完成的工作，不虚构可用工具。

不要为了通过检查，在生成后挑选一个避开变化的小区域充当全部保护内容。先确定保护范围，再编辑和检查；保护范围必须覆盖用户真正要求不变的内容。人物跨越地面边界时也需完整保护。蒙版选择错误时，像素检查通过仍不代表用户要求已满足。

## 可选的本地像素工具

需要 Pillow，仅在实际要做区域合成或像素验证时使用。脚本不调用生图 API，不自动安装依赖，也不识别保护对象。用户或宿主必须先确定保护蒙版。

`scripts/protected_region.py` 接受同尺寸的底图、候选图和灰度蒙版：白色255为完全保护，黑色0为可修改，灰色1–254为可变过渡。过渡必须放在可编辑区域内，不侵占用户指定保护内容。严格保护图像尺寸、原坐标；尺寸不一致直接报错，不自动缩放或对齐。

```sh
python3 scripts/protected_region.py audit --base base.png --candidate candidate.png --mask protection.png --report audit.json
python3 scripts/protected_region.py composite --base base.png --candidate candidate.png --mask protection.png --output final.png --report final-audit.json
```

合成命令只在授权允许本地合成时执行，输出新的 PNG，不覆盖原文件。它将蒙版白色区域从原图原样复制，再回读保存结果验证；报告分别记录候选和最终结果，不能掩盖候选漂移。审计只判断白色区域的像素是否一致，不能判断新对象是否正确、边缘是否自然、保护蒙版是否选对。

## 交付验收与失败处理

- **目标检查**：改动是否符合要求，例如船型、颜色、朝向。
- **保护检查**：与正确基准逐项对照沙纹、文字、位置等。目视结论标明目视；严格像素保留必须有实际区域比对证据。
- **接合检查**：没有接缝、重影、人物截断或不自然的光影。像素不变不等于合成好看。

关键保护项失败时，明确标记失败并回到正确基准修复，不继续基于漂移图叠加。普通单张请求默认最多再尝试一次针对性修复；仍失败则交付失败说明与已有候选，不能无限消耗生成次数，也不能把用户没回复当成扩大范围的许可。用户明确授权更多尝试时按其范围执行。

对外只报告实际完成的检查。一个案例的区域像素不变，不能推广成 Skill 对所有图片都100%准确，也不能当作有无 Skill 的生成质量对照结果。
